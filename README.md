# HUB 3DS·A

Portal web de repaso para 3.º Bachillerato Técnico Vocacional en Desarrollo de Software «A», INDEL, Cantón Lourdes.

**Versión objetivo:** v1.0

## Descripción

HUB 3DS·A reúne fichas de módulos para consultar resúmenes, aprendizajes, programas, herramientas, recursos, evidencias e indicaciones. Los datos se mantienen en `data/modulos.js` y la interfaz los presenta con HTML, CSS y JavaScript nativos.

## Funciones

- Tarjetas y fichas de módulos generadas desde los datos.
- Búsqueda en tiempo real, sin distinguir mayúsculas ni acentos.
- Filtros por docente y tecnología o programa.
- Fichas en ventana de diálogo, con cierre por teclado.
- Seguimiento del progreso guardado localmente en el navegador.
- Quizzes con retroalimentación y resultado.
- Modo claro y oscuro, con preferencia guardada y respeto por la configuración del sistema.
- Diseño adaptable a móvil y navegación por teclado.

## Tecnologías

HTML5, CSS3 y JavaScript puro. No se utilizan frameworks, librerías externas ni CDN.

## Ejecutar en local

1. Clona el repositorio o descarga sus archivos.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Inicia `index.html` con Live Server, o abre `index.html` directamente en un navegador moderno.
4. Para actualizar módulos, edita `data/modulos.js` y recarga la página.

No se requiere instalar dependencias.
